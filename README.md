# 🧒 Smart Waste & Object Detector by Nana (Age 15)

Built by a 15-year-old girl in Kaduna, Nigeria — this AI app uses object detection and voice narration to identify recyclable and organic waste.

## 🌟 Features

- Detects objects in uploaded or webcam images
- Speaks out results in **English, Hausa, Yoruba**, or **Igbo**
- Categorizes items as:
  - ♻️ Recyclable (e.g. bottle, cup)
  - 🍌 Organic (e.g. banana, apple)
  - 👁️ Unknown (any other object)
- Downloadable annotated images and AI chat logs

## 🚀 How to Run Locally

```bash
git clone https://github.com/your-username/smart-waste-detector-nana
cd smart-waste-detector-nana

# Install dependencies
pip install -r requirements.txt

# Make sure yolov5s.pt is in the folder
python app.py
